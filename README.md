# 🏒 Дворовый хоккей 3D

Браузерная 3D-игра в хоккей для игры с друзьями. Камера «из-за спины», как в GTA, мультяшные
«чиби»-хоккеисты из скруглённых кубиков, живые трибуны, мини-карта, звуки.

> 🎮 Есть версия для **Unity** в папке [`unity/`](unity/README.md): там сетевая игра идёт по локальной сети
> или через Radmin VPN / ZeroTier, а матч можно собрать в отдельное приложение.

## Режимы

- **Против ботов**: ты и боты в команде против команды ботов.
- **Вдвоём на одном экране**: экран делится пополам. Можно играть друг против друга или вместе против ботов.
  Второй игрок управляет стрелками или вторым геймпадом.
- **Онлайн с друзьями**: один создаёт матч и получает код из 5 символов (или ссылку), остальные
  подключаются по коду. Свободные места в командах занимают боты. Можно подключиться и во время матча:
  новый игрок заменит бота.

Настройки: от 1 до 5 полевых игроков в команде (плюс вратари-боты), время матча, сложность ботов.
Если в конце основного времени счёт равный, начинается овертайм до первой шайбы.

## Управление

| Действие | Игрок 1 / онлайн | Игрок 2 (сплит-скрин) | Геймпад |
|---|---|---|---|
| Разгон / тормоз, задний ход | `W` `S` (или стрелки в одиночной игре) | `↑` `↓` | левый стик, курки |
| Поворот | `A` `D` | `←` `→` | левый стик |
| Бросок (держи — сильнее) | `Пробел` / ЛКМ | `Enter` / `Num0` | A |
| Пас | `Q` / ПКМ | правый `Shift` / `Num1` | B / Y |
| Силовой приём | `E` | правый `Ctrl` / `Num2` | X |
| Ускорение | `Shift` | `/` / `Num3` | LB / RB |

`Esc` открывает паузу, `H` показывает подсказку по управлению, `M` выключает звук.

Подсказки: бросок, сделанный лицом к воротам, сам доводится в створ. Если нажать бросок, когда к тебе
летит пас, получится бросок «в одно касание». Силовым приёмом соперника сбивают с ног, и он теряет шайбу.

## Как запустить

Игре нужен любой статический веб-сервер, потому что ES-модули не загружаются с `file://`.
Все библиотеки (Three.js, PeerJS) лежат в `lib/`, CDN не нужен.

```bash
python3 -m http.server 8000
```

Потом открой http://localhost:8000.

### Чтобы играть с друзьями по интернету

Проще всего выложить игру на **GitHub Pages**: Settings → Pages → Deploy from a branch → выбрать ветку
и папку `/ (root)`. После этого друзьям достаточно открыть ссылку, нажать «Подключиться» и ввести код.

Онлайн работает через WebRTC (peer-to-peer). Для поиска друг друга используется бесплатный
публичный сервер PeerJS. Хост считает всю физику, поэтому лучше, чтобы хостом был игрок с самым мощным
компьютером и хорошим интернетом. Если соединение не устанавливается (бывает со строгими NAT, например
у некоторых мобильных операторов), попробуйте поменять хоста или подключиться через другую сеть.

## Устройство проекта

```
index.html        меню, лобби, HUD
css/style.css
js/main.js        режимы игры, игровой цикл, HUD, мини-карта
js/sim.js         физика, шайба, вратари, ИИ ботов, упаковка состояния для сети
js/render.js      арена, трибуны со зрителями, камеры, сплит-скрин
js/character.js   модели игроков и их процедурная анимация
js/input.js       клавиатура, мышь, геймпады
js/net.js         онлайн (PeerJS): хост и гость
js/audio.js       синтезированные звуки (WebAudio)
lib/              three.js r170, PeerJS 1.5.4
```

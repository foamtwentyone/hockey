# 🏒 PUCKO — хоккей с характером (Unity)

Мультяшный аркадный хоккей для игры с друзьями: камера «из-за спины», игрушечные хоккеисты с пружинными
анимациями в духе Fall Guys, режим «Аркада» с бонусами, игра вдвоём на одном экране и по сети. Сцену, арену, персонажей, текстуры, звуки и интерфейс скрипты создают сами при
запуске, поэтому в проекте нет моделей, картинок и звуковых файлов.

## Модели персонажей

Хоккеисты сделаны на моделях **KayKit — Adventurers Character Pack** от Kay Lousberg
([kaylousberg.com](https://www.kaylousberg.com), лицензия CC0). Файлы лежат в `Assets/Hockey/Resources/KayKit/`.
Игра перекрашивает форму в цвета команд, прячет оружие и плащи и вкладывает в руку клюшку.
Анимации из набора смешиваются с пружинными наклонами: ноги бегут, а руки держат клюшку.
Если папку с моделями удалить, игра вернётся к простым персонажам из примитивов.

## Как открыть

1. Установи **Unity 6 (6000.0 LTS)** через Unity Hub. Подойдёт и 2022.3 LTS.
2. В Unity Hub нажми **Add → Add project from disk** и выбери папку `unity/` из этого репозитория.
   Если Hub предложит другую версию редактора, соглашайся.
3. При первом открытии Unity установит пакет Input System и может спросить про включение нового
   ввода (*Enable the new Input System backends?*). Подойдёт любой ответ, игра работает с обоими
   вариантами. При ответе «Yes» редактор перезапустится.
4. Скрипт `HockeySetup` сам создаст сцену `Assets/Hockey/Hockey.unity`, добавит её в Build Settings и
   подготовит материалы. Если сцена не открылась, открой её вручную или выбери в меню **Hockey →
   Настроить проект**.
5. Нажми **Play**.

Проект рассчитан на стандартный (Built-in) рендер, как в шаблоне «3D». С URP/HDRP материалы станут
розовыми.

### Сборка игры

**File → Build Profiles** (в 2022.3: *Build Settings*) → Windows / macOS / Linux → **Build**.
Готовую папку можно отправить друзьям, Unity им ставить не нужно.

## Режимы

- **Против ботов.**
- **Вдвоём на одном экране**: экран делится пополам, можно друг против друга или вместе против ботов.
- **Сетевой матч**: один игрок нажимает «Создать сетевой матч», остальные подключаются.
  - **В одной сети (Wi-Fi/LAN)** матч сам появится в главном меню у друзей, останется нажать «Войти».
  - **Через интернет** нужно оказаться в одной виртуальной сети: **Radmin VPN**, **ZeroTier** или
    **Tailscale** (бесплатно, ставится за пару минут). После этого друзья вводят адрес хоста из лобби,
    например `26.12.34.56:7777`. Другой вариант: пробросить на роутере хоста порт **7777 UDP** и
    подключаться по внешнему IP.
  - При первом запуске Windows спросит про брандмауэр: разреши доступ, иначе друзья не подключатся.
  - Друг может подключиться и во время матча: он займёт место бота.

## Режимы матча

- **Классика**: честный хоккей.
- **Аркада**: на льду появляются бонусы.
  - **Турбо**: быстрее катаешься, рывок без усталости.
  - **Мега-бросок**: следующий бросок летит ракетой, вратарю его почти не взять.
  - **Великан**: ты огромный, тебя не сбить, а твои толчки валят с ног.
  - **Магнит**: шайба липнет к клюшке, легче отбирать.
  - **Заморозка**: соперники на пару секунд вмерзают в лёд.

## Управление

Движение задаётся относительно камеры, как в Fall Guys и GTA: «вперёд» значит от камеры. Камера крутится
мышью или правым стиком, а если её не трогать, сама заходит за спину.

| Действие | Один игрок / по сети | Игрок 1 | Игрок 2 | Геймпад |
|---|---|---|---|---|
| Ехать | `W A S D` | `W A S D` | стрелки | левый стик |
| Камера | мышь | сама | сама | правый стик |
| Бросок (держи — сильнее) | ЛКМ / `F` | `F` | `Num0` | RT |
| Пас | ПКМ / `Q` | `Q` | `Num1` | X |
| Прыжок / нырок за шайбой | `Пробел` | `Пробел` | `Num3` | A |
| Силовой толчок | `E` | `E` | `Num2` | B |
| Рывок | `Shift` | `Shift` | `Num4` | LT / LB |

- **Прыжок** на месте помогает перепрыгнуть силовой приём.
- **Нырок** в движении: игрок бросается «рыбкой» и выбивает шайбу.
- Стик против направления движения даёт эффектную остановку со снежной крошкой.

`Esc` открывает паузу, `H` включает и выключает подсказки, `M` выключает звук. Всё остальное настраивается
в меню «Настройки»: громкость, качество графики, угол обзора, дистанция камеры, чувствительность мыши,
инверсия, авто-камера, подсказки, имена над игроками, тряска экрана, размер интерфейса.

## Устройство

```
Assets/Hockey/Scripts/Sim/Sim.cs     физика, шайба, вратари, ИИ ботов (чистый C#, без UnityEngine)
Assets/Hockey/Scripts/Sim/Net.cs     сеть по UDP: хост, гость, поиск матчей в локальной сети
Assets/Hockey/Scripts/HockeyGame.cs  режимы, игровой цикл, камеры, эффекты
Assets/Hockey/Scripts/HockeyGame.UI.cs меню, настройки, лобби, HUD (IMGUI)
Assets/Hockey/Scripts/HockeyGame.Autotest.cs автотест со скриншотами
Assets/Hockey/Scripts/TexArt.cs      процедурные текстуры (лёд, ткань, борта, интерфейс)
Assets/Hockey/Scripts/Fx.cs          частицы и бонусы на льду
Assets/Hockey/Scripts/Settings.cs    настройки игрока
Assets/Hockey/Shaders/HockeyToon.shader мультяшный шейдер
Assets/Hockey/Scripts/Arena.cs       лёд, борта, ворота, трибуны со зрителями, табло, свет
Assets/Hockey/Scripts/CharacterRig.cs модели игроков и пружинная анимация
Assets/Hockey/Scripts/MeshKit.cs     генерация мешей, текстур и материалов
Assets/Hockey/Scripts/GameInput.cs   клавиатура, мышь, геймпады (старый и новый ввод)
Assets/Hockey/Scripts/GameAudio.cs   синтезированные звуки
Assets/Hockey/Editor/HockeySetup.cs  создание сцены и материалов при открытии проекта
```

Хост считает всю физику 60 раз в секунду и 20 раз в секунду рассылает состояние гостям. Гости отправляют
только нажатия и плавно интерполируют полученные кадры.
